### [SuperDARN Data Analysis Working Group (DAWG)](https://superdarn.github.io/dawg/){:target="_blank" rel="noopener"}<br>
I am a member of the SuperDARN Data Analysis Working Group (DAWG), where we review and test code contributions to the [Radar Software Toolkit (RST)](https://radar-software-toolkit-rst.readthedocs.io/en/latest/){:target="_blank" rel="noopener"}. RST is the community's standard software for processing raw SuperDARN radar data into scientific data products, such as maps of ionospheric convection, so that researchers around the world can analyse and visualise the data. Our reviews help keep the toolkit accurate, reliable and well maintained.
